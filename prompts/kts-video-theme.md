## اللي أبيه (عبّي هالخانات)

- **رابط مجلد الدرايف:** `<حط الرابط هنا>`. لازم يكون المجلد مشارك «أي أحد عنده الرابط يقدر يشوف».
- **عنوان الفيديو:** `<مثال: الأكاديميات التابعة لجمعية المعلمين الكويتية>`
- **الأقسام بالترتيب:** كل مجلد فرعي بالدرايف = قسم. اكتب اسم كل قسم مثل ما تبيه يطلع:
  1. `<اسم القسم الأول>` ← مجلد `<اسم المجلد بالدرايف>`
  2. `<اسم القسم الثاني>` ← مجلد `<...>`
  3. ...
- **المقاس:** `16:9` (1920×1080) أو `9:16` (1080×1920).
- **الطول:** حط **كل** المقاطع اللي بالدرايف. الطول ما يهم، المهم ما يكون مختصر.
- **عبارة الختام:** `<مثال: أكاديميات تصنع الفرق>`

**للمقاس العمودي 9:16:** فيه نسخة عمودية من نفس التصميم في الكومت `5d26f71` (`git show 5d26f71:remotion/src/academies/Academies.tsx`)، استخدمها مرجع للمقاسات والمواقع.

### 3. الهيكل

1. **انترو (3 بار):** الشعار كبير مع الأشعة، وجنبه (أو تحته بالعمودي) العنوان، وشارة فيها عدد الأقسام، وقائمة أسماء الأقسام تدخل وحدة ورا الثانية.
2. **لكل قسم:**
   - **بطاقة عنوان (2 بار):** الشارة الذهبية برقم القسم، فوقها «القسم الأول/الثاني…» بالسماوي، والاسم كبير بالأبيض كلمة كلمة، وخط ذهبي بنص معيّن، وتحتها «مقتطفات من برامج …» بالذهبي.
   - **ستارة انتقال:** أشرطة ذهبية وسماوية مائلة، أو مربعات طالعة من تحت.
   - **المقتطفات:** المقاطع ملء الشاشة مع زوم بطيء خفيف، وتداخل ناعم 8 فريم بين اللقطات (بدون فلاش)، وتظليل كحلي فوق وتحت، واسم القسم داخل كبسولة بإطار ذهبي جنب الشعار.
3. **الختام (3 بار):** الشعار كبير، «جمعية المعلمين الكويتية»، وعبارة الختام بالذهبي، وأسماء الأقسام كبسولات، وبعدها يتلاشى للكحلي.

كل القصات على الإيقاع: اللقطة نص بار (35/34 فريم بالتناوب) أو بار كامل (69). ومجموع كل قسم لازم يكون مضاعف للبار.

### 4. خطوات العمل

1. **الشبكة:** التحميل يحتاج `drive.usercontent.google.com` و`drive.google.com`. بيئة `jenan-video-editor` تسمح فيهم. إذا انرفض الاتصال، انقل الجلسة لهالبيئة.
2. **اقرأ المجلد:** استخدم أدوات Google Drive (`search_files` مع `parentId = '<id>'`) وامشِ على المجلدات الفرعية كلها، حتى المجلدات اللي بالتاريخ داخل كل قسم.
   تجاهل ملفات `._*` (هذي ملفات ماك فاضية).
3. **نزّل وحوّل:** سوّ ملف `list.txt` كل سطر فيه `قسم file_id اسم مجلد_النسخ`، وشغّل:
   ```bash
   xargs -P 3 -L 1 tools/drive_fetch.sh < list.txt
   ```
   المقاطع الأصلية 4K وثقيلة. السكربت يحولها 1080p/30 ويحذف الأصلي.
   خلي مجلد النسخ برا المستودع (مثلاً بالـscratchpad)، وشغله بالخلفية لأنه ياخذ وقت.
4. **عاين:** `python tools/contact_sheet.py <مجلد_النسخ> <قسم> <مجلد_الصور>`، وشوف الصور عشان تعرف المقاطع اللي فيها جزء خربان (أحد يمر قدام الكاميرا، أو شاشة سودا).
5. **قائمة اللقطات:** احسب المدد بملف `durs.txt`، وبعدين شغّل:
   ```bash
   python tools/academies_shots.py durs.txt shots.json <قسم1> <قسم2> ...
   ```
   حط الاستثناءات اليدوية في `OVR` داخل السكربت، وانقل الناتج لـ `config.ts` الجديد.
6. **انسخ المقاطع المستخدمة** لـ `remotion/public/footage/<اسم-جديد>/`. هالمجلد ما يرتفع للمستودع.
7. **الموسيقى بطول الفيديو:** احسب عدد البارات (3 انترو + لكل قسم 2 + بارات المقتطفات + 3 ختام) وشغّل:
   ```bash
   python tools/compose_formal.py --sf2 GeneralUser-GS.sf2 --style soft --bpm 104.3478 \
     --intro 3 --recs <بارات الوسط> --rec-bars 1 --outro 3 -o music.wav
   ```
   الـSoundFont موجود على `https://raw.githubusercontent.com/mrbumpy409/GeneralUser-GS/main/GeneralUser-GS.sf2`، ويحتاج `pip install --no-deps tinysoundfont`.
   حوّل الملف لـ mp3 وحطه في `remotion/public/<اسم-جديد>/music.mp3`.
8. **تحقق قبل الرندر:** سوّ `npx remotion still` لعدة فريمات (الانترو، بطاقة عنوان، لقطة من المقتطفات، الختام)، وتأكد إن النصوص ما تنكسر لسطرين وإن المسافات بين الكلمات طبيعية.
9. **الرندر:**
   ```bash
   cd remotion && npx remotion render src/index.ts <CompositionId> out/<name>.mp4 --concurrency=4 --crf=18
   ```
10. **نسخة للتسليم:** الملف الكامل يطلع كبير (فوق 300 ميغا) وما يقدر الجوال يحفظه. سوّ نسخة 74 ميغا تقريباً:
    ```bash
    ffmpeg -i out/<name>.mp4 -c:v libx264 -preset slow -b:v 1500k -pass 1 -an -f null /dev/null
    ffmpeg -i out/<name>.mp4 -c:v libx264 -preset slow -b:v 1500k -pass 2 -c:a aac -b:a 128k -movflags +faststart out/<name>-small.mp4
    ```
    إذا لا زال كبير، قسّمه جزء لكل قسم. أرسله كملف للتحميل (attach) مو معاينة.
11. **ارفع الكود** (بدون المقاطع) على فرع العمل.

### 5. قواعد

- لا تكتب معلومات عن الأقسام ما هي موجودة بالمجلد. خلي النصوص عامة («مقتطفات من برامج الأكاديمية»)، وإذا كتبت عبارة من عندك قل للمستخدم.
- لا تشيل مقاطع إلا اللي أقصر من 1.2 ثانية، أو اللي كلها خربانة، وقل للمستخدم وش شلت وليش.
- خلّ صوت المقاطع الأصلي مقفول. يشتغل بس الموسيقى والمؤثرات.
