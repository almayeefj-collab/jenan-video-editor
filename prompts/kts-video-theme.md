# برومت: فيديو بهوية جمعية المعلمين الكويتية من مجلد درايف

> **طريقة الاستخدام:**
> 1. افتح Claude Code (claude.ai/code) على مستودع **`almayeefj-collab/jenan-video-editor`**، فرع **`claude/focused-dirac-2783en`**. إذا الفرع اندمج في `main`، اشتغل على `main`.
> 2. اختار بيئة تسمح بالتحميل من جوجل درايف، يعني فيها `drive.usercontent.google.com` و`drive.google.com`.
> 3. الصق هالملف كامل في المحادثة، وعبّي الخانات تحت «اللي أبيه». أهم شي **رابط الدرايف**، والباقي Claude يستنتجه من أسماء المجلدات إذا تركته فاضي.

---

## اللي أبيه

- **رابط مجلد الدرايف:** `<حط الرابط هنا>`. لازم يكون المجلد مشارك «أي أحد عنده الرابط يقدر يشوف».
- **العنوان الرئيسي:** `<مثال: الأكاديميات التابعة لجمعية المعلمين الكويتية>`
- **الأقسام بالترتيب:** كل مجلد فرعي بالدرايف = قسم.
  1. `<اسم القسم كما يطلع بالفيديو>` ← مجلد `<اسم المجلد بالدرايف>`
  2. ...
- **الطول:** `<مثال: 3 دقايق تقريباً>` أو `كل المقاطع`.
- **عبارة الختام:** `<مثال: أكاديميات تصنع الفرق>`
- **المقاس:** `16:9` (1920×1080) للتلفزيون، وهذا الافتراضي.

## المطلوب من Claude

سوّ فيديو جديد بـ Remotion **بنفس الهوية البصرية ونفس الانتقالات بالضبط** مثل فيديو الأكاديميات الموجود.
**لا تصمم شي جديد ولا تغيّر أي ستايل.** انسخ القالب وغيّر البيانات بس: النصوص، واللقطات، والموسيقى بالطول الجديد.

### 1. القالب (انسخه حرفياً)

| الملف | وش فيه |
|---|---|
| `remotion/src/academies/Academies.tsx` | التصميم والحركات والانتقالات كلها |
| `remotion/src/academies/config.ts` | أسماء الأقسام وقوائم اللقطات. **هذا بس اللي يتغير** |
| `remotion/src/conference46/config.ts` | الألوان `C` ومسار الشعار `LOGO` |
| `remotion/src/reel/font.ts` | الخطوط: Cairo للعربي، Playfair Display للأرقام |

1. انسخ مجلد `remotion/src/academies/` لمجلد جديد، مثلاً `remotion/src/<اسم-الفيديو>/`.
2. داخل النسخة غيّر بس:
   - مسار اللقطات `CLIP_DIR`.
   - مسار الموسيقى (`academies/music.mp3` ← `<اسم-الفيديو>/music.mp3`).
   - النصوص الثابتة إذا الموضوع مو أكاديميات: العنوان الرئيسي، وكلمة «أكاديميات» تحت الرقم، و«مقتطفات من برامج الأكاديمية»، وعبارة الختام.
   - **لا تلمس** المقاسات والألوان والتوقيتات والحركات.
3. سجّل Composition جديد في `remotion/src/Root.tsx` بنفس طريقة `Academies`.
4. لا تعدّل ملفات الفيديوهات القديمة.

### 2. الهوية البصرية (للتحقق إن النسخة طابقت الأصل)

- **الخلفية:** سماء كحلية بتدرج شعاعي (`#174c9a` ← `#0d2f6e` ← `#071c45` ← `#041230`)، و170 نجمة تلمع وتطلع ببطء، وكوكب مضيء أسفل الشاشة بحافة سماوية متوهجة.
- **الألوان:** سماوي `#7fe6f2`، ذهبي `#f6b65b` / `#e88a2c`، أبيض للعناوين.
- **الشعار:** `remotion/public/brand/kts-logo.png` مع أشعة ذهبية تدور خلفه.
  - بالانترو فوق بالنص.
  - بعدها ينتقل صغير للزاوية اليمين فوق طول الفيديو.
  - بالختام يرجع كبير فوق بالنص.
- **الخط كبير وواضح للتلفزيون:**
  - العنوان الرئيسي 82px بسطر واحد.
  - اسم القسم بالبطاقة 150px.
  - «الأكاديمية الأولى» 68px، و«مقتطفات…» 62px.
  - اسم الجمعية بالختام 108px، وعبارة الختام 70px.
- **الشارة الذهبية:** دائرة متدرجة فيها رقم القسم (01، 02، 03) بخط Playfair، تدخل بـ spring مع لفة.

### 3. الهيكل والانتقالات (نفسها بالضبط)

التوقيت كله بالـ bar: ‏1 بار = 69 فريم = 2.3 ثانية على 30fps، والـ BPM ‏104.3478.

1. **الانترو (4 بار):**
   - الشعار يطلع فوق بالنص، يكبر بـ spring، مع boom.
   - تحته العنوان الرئيسي: أول جزء بالسماوي والباقي بالأبيض.
   - تحته الشارة الذهبية بعدد الأقسام + كلمة «أكاديميات» بالذهبي.
   - تحتها كبسولات أسماء الأقسام بالترتيب، كل وحدة تدخل من جهة، مع pop.
   - بالنهاية النصوص تطلع لفوق وتختفي، والشعار يروح للزاوية.
2. **لكل قسم:**
   - **بطاقة عنوان (2 بار):**
     - أشعة ذهبية، والشارة برقم القسم فوق.
     - تحتها «الأكاديمية الأولى/الثانية/الثالثة» بالسماوي.
     - بعدها اسم القسم كلمة كلمة (blur + صعود).
     - بعدها خط ذهبي بنص معيّن، و«مقتطفات من برامج الأكاديمية» بالذهبي.
     - تطلع البطاقة بزوم + blur.
   - **ستارة الانتقال:** بالتناوب بين أشرطة ذهبية وسماوية مائلة تمسح الشاشة، ومربعات ذهبية وسماوية طالعة من تحت.
   - **المقتطفات:**
     - تدخل بدائرة تنفتح من النص.
     - كل لقطة ملء الشاشة مع زوم بطيء وحركة خفيفة يمين ويسار.
     - بين اللقطات تداخل ناعم 8 فريم، **بدون فلاش**.
     - تظليل كحلي فوق وتحت.
     - اسم القسم داخل كبسولة بإطار ذهبي جنب الشعار.
3. **الختام (3 بار):**
   - الشعار يرجع كبير.
   - تحته «جمعية المعلمين الكويتية»، وبعدها عبارة الختام بالذهبي، وكبسولات الأقسام.
   - بعدها يتلاشى للكحلي.
4. **دايماً موجود:** تحت نقاط تقدّم (القسم الحالي ذهبي عريض) وتحتها «جمعية المعلمين الكويتية».
5. **الصوت:** موسيقى هادية بس، وصوت المقاطع الأصلي مقفول. المؤثرات من `remotion/public/sfx/` بنفس أماكنها بالقالب.

### 4. خطوات الشغل

1. **اقرأ الدرايف:** استخدم أدوات Google Drive (`search_files` مع `parentId = '<id>'`).
   - امش على كل المجلدات الفرعية، حتى مجلدات التواريخ داخل كل قسم.
   - تجاهل ملفات `._*` (هذي ملفات ماك فاضية حجمها 4KB).
   - إذا رد البحث بـ `ancestors` فاضي، استخدم `parentId` مجلد مجلد.
2. **نزّل وحوّل بالخلفية** (ياخذ وقت لأن المقاطع 4K):
   - سوّ ملف `list.txt`، كل سطر فيه `قسم file_id اسم مجلد_النسخ`. القسم كلمة إنجليزية قصيرة مثل `lead` أو `dev`.
   - خلي مجلد النسخ برا المستودع، بالـscratchpad.
   - شغّل:
     ```bash
     xargs -P 3 -L 1 tools/drive_fetch.sh < list.txt
     ```
   - إذا انرفض الاتصال بـ `drive.usercontent.google.com`، البيئة ما تسمح فيه. انقل الجلسة لبيئة تسمح.
3. **عاين المقاطع:**
   ```bash
   python tools/contact_sheet.py <مجلد_النسخ> <قسم> <مجلد_الصور>
   ```
   وشوف الصور. سجّل أي مقطع فيه جزء خربان، مثل أحد يمر قدام الكاميرا أو شاشة سودا.
4. **قِس الاهتزاز:**
   ```bash
   python tools/shake_profile.py <مجلد_النسخ> motion.json
   ```
5. **قص اللقطات على الإيقاع:**
   ```bash
   for f in <مجلد_النسخ>/*.mp4; do echo "$(basename $f .mp4) $(ffprobe -v error -show_entries format=duration -of csv=p=0 $f)"; done > durs.txt
   python tools/academies_shots.py durs.txt shots.json --motion motion.json lead:24 dev techno:24
   ```
   - `قسم:رقم` = عدد البارات لهالقسم، ويختار مقاطع موزعة بالتساوي على كل الأيام.
   - `قسم` بدون رقم = كل مقاطعه.
   - للوصول لطول معيّن: (الطول بالثواني ÷ 2.3) − 4 انترو − 3 ختام − 2 لكل بطاقة = بارات المقتطفات. وزّعها على الأقسام.
   - كل لقطة تنأخذ من أثبت جزء بالمقطع، والمقاطع المهتزة أو الأقصر من 1.2 ثانية تنشال.
   - الأجزاء الخربانة اللي لقيتها بالخطوة 3 حطها في `OVR` داخل السكربت.
   - انقل الناتج لـ `config.ts` الجديد **بالترتيب اللي طلبه المستخدم**.
6. **انسخ المقاطع المستخدمة بس** لـ `remotion/public/footage/<اسم-الفيديو>/`. هالمجلد ما يرتفع للمستودع.
7. **الموسيقى بطول الفيديو:**
   - احسب: بارات الوسط = مجموع (2 + بارات مقتطفات كل قسم).
   - السكربت يحتاج `pip install --no-deps tinysoundfont`، والـSoundFont من `https://raw.githubusercontent.com/mrbumpy409/GeneralUser-GS/main/GeneralUser-GS.sf2`.
   - شغّل:
     ```bash
     python tools/compose_formal.py --sf2 GeneralUser-GS.sf2 --style soft --bpm 104.3478 \
       --intro 4 --recs <بارات الوسط> --rec-bars 1 --outro 3 -o music.wav
     ffmpeg -i music.wav -b:a 192k remotion/public/<اسم-الفيديو>/music.mp3
     ```
8. **تحقق قبل الرندر:** سوّ `npx remotion still` لفريمات من الانترو، وبطاقة عنوان، ولقطة من المقتطفات، والختام. وتأكد من:
   - العنوان الرئيسي بسطر واحد.
   - ما في نص يلمس خط الكوكب تحت.
   - المسافات بين الكلمات طبيعية.
   - إذا اسم قسم طويل ونزل سطرين ببطاقة العنوان، صغّره بـ `titleSize` بالـconfig لذاك القسم بس.
9. **الرندر:**
   ```bash
   cd remotion && npx remotion render src/index.ts <CompositionId> out/<name>.mp4 --concurrency=4 --crf=18
   ```
10. **نسخة للتسليم:** الملف الكامل حوالي 200 ميغا والجوال ما يحفظه. سوّ نسخة حوالي 55 ميغا لكل 3 دقايق:
    ```bash
    ffmpeg -y -i out/<name>.mp4 -c:v libx264 -preset slow -b:v 2200k -pass 1 -an -f null /dev/null
    ffmpeg -y -i out/<name>.mp4 -c:v libx264 -preset slow -b:v 2200k -pass 2 -c:a aac -b:a 128k -movflags +faststart out/<name>-tv.mp4
    ```
    أرسلها كملف للتحميل (attach)، مو معاينة.
11. **ارفع الكود** (بدون المقاطع) على فرع العمل.

### 5. وضع «موضوع واحد» (مجلد واحد بدون أقسام)

إذا الفيديو عن موضوع واحد، مثل «بروتوكول التعاون مع وزارة التربية»، وكل مقاطعه بمجلد واحد (حتى لو داخله مجلدات بالتواريخ)، نفس الهوية والانتقالات تبقى، والتغييرات بس:

- **الانترو (4 بار):** الشعار فوق بالنص، وتحته العنوان الرئيسي كبير **بسطرين**:
  - السطر الأول بالسماوي: «بروتوكول التعاون».
  - السطر الثاني بالأبيض: «بين جمعية المعلمين الكويتية ووزارة التربية».
  - تحت العنوان خط ذهبي بنص معيّن.
  - تحته سطر ذهبي: «مقتطفات من الفعاليات».
  - **شيل** الشارة اللي فيها العدد، وكبسولات الأقسام.
- **بطاقة العنوان:** وحدة بس بعد الانترو، أو شيلها إذا الانترو كافي. وإذا خليتها، **بدون** شارة الرقم وبدون «الأكاديمية الأولى».
- **المقتطفات:**
  - كل المقاطع بمقطع واحد بالترتيب الزمني، والكبسولة اللي جنب الشعار فيها اسم الموضوع.
  - إذا المجلد فيه مجلدات بالتواريخ، خلها كلها قسم واحد بالترتيب الزمني. **لا تخترع** أسماء لفعاليات كل يوم.
  - شيل نقاط التقدم تحت وخل بس «جمعية المعلمين الكويتية».
- **الختام:** الشعار كبير، وتحته «جمعية المعلمين الكويتية»، وبعدها اسم الموضوع بالذهبي، و**بدون** كبسولات.
- **قص اللقطات:** قسم واحد، مثلاً:
  ```bash
  python tools/academies_shots.py durs.txt shots.json --motion motion.json proto:70
  ```
  - 70 بار تقريباً = 3 دقايق مع الانترو والختام.
  - الموسيقى: `--intro 4 --recs <بارات المقتطفات (+2 إذا فيه بطاقة)> --outro 3`.

### 6. قواعد

- الهوية والانتقالات نفسها بالضبط. لا تغيّر ألوان ولا خطوط ولا مقاسات ولا حركات.
- لا تكتب معلومات عن الأقسام ما هي موجودة بالدرايف. وإذا كتبت عبارة من عندك، قل للمستخدم.
- قل للمستخدم وش المقاطع اللي انشالت وليش.
- خلي صوت المقاطع الأصلي مقفول.
