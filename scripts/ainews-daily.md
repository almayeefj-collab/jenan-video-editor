# سلسلة «آخر أخبار أدوات الـ AI مع جنان المعييف» — طريقة إنتاج الحلقة

حلقة يومية (٣٥–٥٠ ثانية، 9:16) عن آخر أخبار أدوات الذكاء الاصطناعي: إصدارات جديدة
وخاصيات تقدر تستفيد منها. الفويس أوفر **بصوت جنان** (تسجله هي)، والموسيقى حماسية تحته.
آخر الحلقة دايماً: «تابعوني على الانستغرام @t.jenanalmayeef4».

الكود: `remotion/src/ainews/` (القالب `AiNews.tsx`، الحلقات في `episodes/`).
الحلقة ١ (`episodes/ep01.ts`) هي المرجع: انسخها لكل حلقة جديدة.

## الهيكل

| المشهد | المحتوى | الصورة |
|---|---|---|
| hook | «آخر أخبار أدوات الـ AI» + «مع جنان المعييف» | ثابتة: `ainews/brand/intro.jpg` |
| news × ٣–٤ | tag الأداة + عنوان قصير + سطر شرح | جديدة من Higgsfield لكل خبر |
| outro | «تبي الأخبار أول بأول؟ تابعوني على الانستغرام» + الحساب | ثابتة: `ainews/brand/outro.jpg` |

## المرحلة ١ — كل يوم الصبح (بدون صوت)

1. **الأخبار**: أخبار آخر ٢٤–٤٨ ساعة (WebSearch extended). مصادر رسمية (release notes) + موقع
   تقني معروف. ٣–٤ أخبار، وخبر واحد على الأقل «خاصية تفيدك». لا تكرر خبر من حلقة سابقة
   (اقرأ `remotion/src/ainews/episodes/*.ts`). لا تخترع تفاصيل.
2. **السكربت** (لهجة خليجية، جمل قصيرة) — فقرة لكل مشهد:
   - المقدمة دايماً: `آخر أخبار أدوات الـ AI مع جنان المعييف! الحلقة <الرقم بالكلام>.`
   - فقرة لكل خبر (١٥–٢٥ كلمة).
   - الختام دايماً: `تبون الأخبار أول بأول؟ تابعوني على الانستغرام، والحلقة الجاية بكرة!`
   احفظه في `remotion/public/ainews/epNN/script.txt` (فقرة بكل سطر).
3. **الصور (Higgsfield)**: `generate_image_batch`، موديل `gpt_image_2_5`، `aspect_ratio: 9:16`، صورة
   لكل خبر. ستايل سينمائي غامق بإضاءة بنفسجي/أزرق/ملون، بدون نص ولا شعارات.
   **بدون أشخاص يتصورون سيلفي** (جنان ما حبتها) — أشياء/أجهزة/مشاهد. (~٠.٢٥ كريدت للصورة)
   نزّلها لـ `remotion/public/ainews/epNN/s1.jpg ...` (حوّل PNG لـ JPG) وشوفها قبل الاستخدام.
4. **الحلقة**: `episodes/epNN.ts` (انسخ ep01) واضفها في `episodes/index.ts`. بدون `voice`،
   و `dur` تقديري = عدد كلمات الفقرة ÷ ٢.٥ + ٠.٥ ثانية. hook و outro يستخدمون صور `brand/`.
5. **الموسيقى**:
   ```bash
   python3 tools/compose_hype.py --seconds <الطول الكلي> --hits 0.2 <بداية كل مشهد...> -o /tmp/m.wav
   ffmpeg -i /tmp/m.wav -b:a 192k remotion/public/ainews/epNN/music.mp3
   ```
6. **تشييك ورندر**: stills من نص كل مشهد (`npx remotion still ... --frame=N`) وتأكد إن النص ما
   ينقص ولا الإنجليزي ينقلب. بعدين `npx remotion render src/index.ts AiNewsNNMusic out/ainews-epNN-music.mp4`
   وضغط تحت ٣٠MB: `ffmpeg -i in.mp4 -c:v libx264 -crf 23 -c:a aac -b:a 160k -movflags +faststart out-ig.mp4`.
7. **أرسل لجنان**: الفيديو (موسيقى بس) + السكربت كامل في نص واحد عشان تسجله + كابشن جاهز.
   ذكّرها: تسكت ثانية بين كل فقرة.

## المرحلة ٢ — لما ترسل جنان تسجيلها

```bash
python3 tools/split_voice.py <التسجيل> remotion/public/ainews/epNN/script.txt remotion/public/ainews/epNN
```
يقطّعه v0..vN.mp3 وينظفه. حط `voice` لكل مشهد (v0 للـ hook، v1.. للأخبار، الأخير للأوترو)
و `dur = طول المقطع + 0.2` (الـ hook: + 0.27). الأوترو يبقى ٧ ثواني. عِد الموسيقى بالأوقات الجديدة،
ورندر `AiNewsNN` بالصوت، وطبّع الصوت للإنستغرام:
`ffmpeg -i out.mp4 -c:v libx264 -crf 23 -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k -movflags +faststart out-ig.mp4`.
احفظ التسجيل الأصلي في `epNN/raw/`.
